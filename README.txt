OpenWithLove Catalogue

The catalogue opens with three collection folders:
1. Birthdays — existing B1-B6 templates and sample.
2. Anniversaries — existing A1-A6 templates and colour variations.
3. Invitations — Traditional Wedding Invitation (I1).

The Invitations collection links to:
https://komaliandhavarapu.github.io/invitation/

To update GitHub Pages, upload/commit the contents of this folder to the existing catalogue repository. Existing birthday and anniversary links and styling have been preserved.
